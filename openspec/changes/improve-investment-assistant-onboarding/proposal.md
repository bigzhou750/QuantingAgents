## Why

个人投资助手和 Agent 评测能力已经具备路由与基础页面，但侧边栏入口不可用或不可见，新手用户也缺少从“首次配置”到“策略选择/策略筛选/体检/验证”的清晰路径。对面向炒股新手的个人量化助手而言，可发现性、默认模板、向导式任务、策略匹配解释和证据分层直接决定用户能否顺利上手。

本变更在现有画像、策略、选股、体检、VibeAgent 上下文注入和 runtime 验证工具基础上，补齐导航入口与新手引导体验，使用户能在较少学习成本下完成第一次个性化研究闭环，并能理解“为什么选这个策略”“这个策略是否适合当前市场”“当前证据是否足够可靠”。

## What Changes

- 修复侧边栏菜单入口，展示个人投资助手和 Agent 评测入口，并修正现有菜单项中的异常引号导致的路由不可点击问题。
- 在个人投资助手中增加首次使用引导和画像模板，帮助用户快速生成保守、平衡、进取等基础画像。
- 在策略管理中增加默认策略模板或策略卡片，并补充策略选择向导，降低用户从空白策略开始配置的门槛。
- 将策略选股和策略体检发起流程改造成更明确的任务向导，允许用户确认策略、参数、是否带入画像上下文，以及是否需要进一步回测/验证。
- 优化策略选股和体检结果页，强化“为什么入选、风险在哪里、与我的画像是否冲突、下一步可做什么”的解释。
- 增加观察池、复盘入口和证据解释入口，使筛选、体检和研究结果能进入后续跟踪流程。
- 统一新手友好的术语解释和非荐股表述，避免把候选池或体检结果误读为买卖建议。
- 明确系统只能给出“策略适配度、证据强弱、验证结果”和“候选研究方向”，不能声称保证收益或替用户承诺盈利。
- **非目标**：本次不实现完整回测平台、不新增权限控制、不改变会员/计费/多租户策略，也不做真正意义上的收益承诺或荐股推荐。

## Capabilities

### New Capabilities
- `investment-assistant-onboarding`: 个人投资助手的新手引导、默认模板、任务向导、结果解释、观察池和复盘入口。
- `application-navigation`: 主侧边栏菜单的关键功能入口可发现性。

### Modified Capabilities
- 无。本变更增强现有个人投资助手和评测平台的入口与体验，不改变其核心数据契约。

## Impact

- **前端**：修改 `SidebarMenu.vue`、个人投资助手页面、结果页和相关路由入口；暂不做菜单权限过滤。
- **后端**：可能需要新增默认模板读取接口、观察池/复盘入口所需的轻量记录 API，或复用现有自选股/任务结果接口。
- **后端**：可能需要新增默认模板读取接口、策略选择建议接口、验证任务入口，或复用现有自选股/任务结果接口与回测工具。
- **VibeAgent 链路**：增强任务发起时的上下文选择体验，并在需要时串联策略发现、回测和风险工具，不改变 runtime 执行语义。
- **文档**：需要补充个人投资助手的新手工作流说明和菜单入口说明。
- **兼容性**：现有画像、策略、策略选股、策略体检、Agent 评测和自然语言研究 API 应保持兼容。
