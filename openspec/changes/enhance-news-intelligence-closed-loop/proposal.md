## Why

当前新闻关注能力已经具备收集、工作台、持仓影响分析和模拟告警的基础骨架，但仍停留在“几条标题 + 低中高等级”的原型形态。真实投资研究需要更稳定的新闻供给、更强的事件理解、更清晰的持仓影响路径，以及从观察、告警到复盘的闭环。

## What Changes

- 增强新闻数据源聚合与降级链路，避免单一新闻源失败或近期库为空时直接显示“暂无新闻”。
- 将关注工作台从“收集记录列表”升级为“新闻研究工作台”，支持按关注对象、持仓、自选、行业、事件主题组织新闻。
- 为单条新闻、批量新闻和主题聚类增加 Agent 分析入口，输出行业板块影响、上下游传导、持仓命中、影响路径、证据强度和后续观察点。
- 将持仓新闻影响分析改为自动加载和后台刷新，用户进入页面即可看到最新可用分析结果，并可手动重新分析。
- 扩展影响分析指标，从单一三档等级升级为多维评分：方向、强度、时间窗口、暴露度、证据质量、市场确认、风险类型和待验证指标。
- 增加新闻事件聚类、去重、来源覆盖、数据新鲜度和失败原因展示，避免重复标题刷屏或静默失败。
- 增加观察任务和复盘闭环：从新闻影响生成观察项，后续跟踪价格、成交量、资金流、公告和行业数据是否验证原判断。
- 保持研究边界：所有输出必须是研究解释、风险提示和观察计划，不得输出买卖指令、收益承诺或自动交易动作。

## Capabilities

### New Capabilities

- `news-source-coverage-and-fallback`: 多源新闻聚合、数据源健康、降级查询、冷启动兜底和可解释的数据覆盖状态。
- `news-agent-impact-analysis`: 新闻 Agent 分析入口、结构化 prompt、行业板块/上下游/持仓影响解析和可复核分析结果。
- `news-research-closed-loop`: 新闻事件聚类、观察任务、告警确认、后续复盘和研究闭环状态管理。

### Modified Capabilities

- 无。当前主规格尚未归档新闻关注能力，本次以新增生产级闭环能力表达对 `news-watch-and-holdings-impact` 的迭代增强。

## Impact

- **前端**：影响 `frontend/src/views/NewsWatch/*`、股票详情新闻区、自选/持仓相关入口、告警配置和可能新增的新闻分析详情页、事件详情页、观察任务面板。
- **后端 API**：需要新增或扩展新闻聚合、来源健康、事件分析、持仓自动分析、观察任务、复盘记录等接口；现有 `/api/news-watch/*` 和 `/api/news-data/*` 需要保持兼容。
- **数据服务**：需要复用并增强 `news_data_service`、现有 AKShare/东方财富链路、favorites、investment profile、alerts；可新增轻量集合保存新闻事件、分析结果、观察任务和复盘状态。
- **Agent 能力**：需要复用现有 VibeAgent/LLM 调用能力作为新闻影响分析器，输入必须包含可追溯新闻、来源、时间、关联标的和用户持仓上下文。
- **权限与审计**：所有用户级分析、关注、告警、观察和复盘记录必须按 `user_id` 隔离，并保留触发来源、请求参数和生成时间。
- **验证**：验收必须包含真实 HTTP 数据链路验证，不得只用字符串单测证明完成；新闻源故障、空库、无持仓、新闻过期和 Agent 失败都必须有降级结果。
