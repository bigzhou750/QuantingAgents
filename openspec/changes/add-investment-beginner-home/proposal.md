## Why

个人投资助手现有入口偏工具化，新手用户进入后需要自行理解画像、策略、选股、体检之间的关系，容易不知道下一步该做什么。需要新增一个面向新手的首页和菜单结构，把已有能力组织成清晰的第一步、下一步和复盘路径。

## What Changes

- 新增个人投资助手“新手首页”，按用户状态展示下一步行动。
- 调整个人投资助手菜单信息架构：保留投资画像，新增策略广场、我的策略、我的观察等面向任务的入口。
- 将选股结果、体检结果从一级菜单降级为带上下文的二级页面入口，仍保留路由兼容。
- 首页展示画像完成度、推荐策略方向、最近观察、模拟练习入口和数据状态摘要。
- 页面文案面向新手，避免要求用户先理解专业指标。
- 不改变登录权限要求，仍复用现有认证和用户隔离。

## Capabilities

### New Capabilities

- `investment-beginner-home`: 面向新手的个人投资助手首页、导航结构和下一步行动引导。

### Modified Capabilities

- 无。

## Impact

- 影响 `frontend/src/router/index.ts`、`frontend/src/components/Layout/SidebarMenu.vue`、`frontend/src/utils/sidebarEntries.ts` 和个人投资助手相关前端页面。
- 可能新增用于首页聚合数据的后端 API，复用投资画像、策略、任务、自选股、模拟交易、新闻关注等现有服务。
- 不引入新外部依赖。
- 不改变现有个人投资助手 API 的认证要求。
- 保留旧结果页路由，避免历史链接失效。
