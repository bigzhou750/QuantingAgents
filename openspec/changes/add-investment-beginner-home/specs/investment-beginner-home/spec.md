## Purpose

提供一个面向新手的个人投资助手入口，将画像、策略、观察、模拟和复盘组织成用户能理解的下一步行动路径。

## ADDED Requirements

### Requirement: 新手首页展示下一步行动

系统 SHALL 在个人投资助手默认入口展示一个新手首页，并根据用户当前状态给出明确的下一步行动。

#### Scenario: 用户尚未设置画像

- **WHEN** 已登录用户进入个人投资助手且不存在投资画像
- **THEN** 系统 MUST 将“完成投资画像”展示为主要行动

#### Scenario: 用户已有画像但没有策略

- **WHEN** 已登录用户进入个人投资助手且已有画像但没有启用策略
- **THEN** 系统 MUST 展示适合画像的策略方向入口

#### Scenario: 用户已有策略但没有观察标的

- **WHEN** 已登录用户进入个人投资助手且已有启用策略但没有观察标的
- **THEN** 系统 MUST 展示生成本期观察标的的行动入口

#### Scenario: 用户已有模拟持仓

- **WHEN** 已登录用户进入个人投资助手且存在模拟持仓
- **THEN** 系统 MUST 展示模拟持仓摘要和待复盘入口

### Requirement: 菜单结构面向用户任务

系统 SHALL 将个人投资助手菜单组织为新手首页、投资画像、策略广场、我的策略、我的观察等任务型入口。

#### Scenario: 展示一级菜单

- **WHEN** 用户打开侧边栏个人投资助手分组
- **THEN** 系统 MUST 展示面向任务的入口名称，而不是只展示结果页入口

#### Scenario: 访问历史选股结果链接

- **WHEN** 用户访问已有的选股结果路由
- **THEN** 系统 MUST 保持页面可访问，并展示结果所属策略和任务上下文

#### Scenario: 访问历史体检结果链接

- **WHEN** 用户访问已有的体检结果路由
- **THEN** 系统 MUST 保持页面可访问，并展示结果所属策略和任务上下文

### Requirement: 首页聚合信息遵守用户隔离

系统 SHALL 只展示当前登录用户的画像、策略、观察、任务、模拟和新闻摘要。

#### Scenario: 聚合首页数据

- **WHEN** 后端返回个人投资助手首页摘要
- **THEN** 响应 MUST 只包含当前用户有权访问的数据

#### Scenario: 未登录访问

- **WHEN** 未登录用户访问个人投资助手首页 API 或页面
- **THEN** 系统 MUST 按现有认证机制拒绝访问或跳转登录

### Requirement: 新手文案避免专业门槛

系统 SHALL 在首页和主要行动入口使用新手可理解的文案，并把专业指标解释放在展开或详情中。

#### Scenario: 展示策略方向

- **WHEN** 首页展示策略方向
- **THEN** 系统 MUST 使用“找什么、适合谁、风险是什么”解释策略，而不是只展示指标名称

#### Scenario: 展示数据状态

- **WHEN** 首页展示数据状态
- **THEN** 系统 MUST 使用“数据截至时间”和“是否足够支持结果”等表达
