## Context

现有个人投资助手路由默认跳转到 `/investment/profile`，侧边栏包含投资画像、策略管理、选股结果、体检结果。已有后端服务可读取画像、策略、策略任务和结果；模拟交易、新闻关注、自选股也已有独立接口。

## Goals / Non-Goals

**Goals:**

- 建立新手首页作为 `/investment` 默认入口。
- 用状态驱动的下一步行动串联画像、策略、观察、模拟和复盘。
- 调整菜单可发现性，同时保留结果页历史路由。
- 复用现有服务聚合摘要，不在本 change 中实现策略广场和观察池完整能力。

**Non-Goals:**

- 不实现策略广场的完整卡片和详情能力。
- 不实现历史模拟、回测或数据自动更新。
- 不改造模拟交易订单模型。

## Decisions

1. 新增首页而不是继续强化画像页
   - 理由：画像页是配置页面，不适合承担全局导航和下一步行动。
   - 替代方案：在画像页顶部塞入口，会让配置页越来越重。

2. 结果页保留路由但从菜单降级
   - 理由：选股结果和体检结果需要任务上下文，直接作为菜单项容易让用户困惑。
   - 替代方案：删除路由会破坏历史任务链接。

3. 首页摘要 API 采用聚合接口
   - 理由：前端首页需要一次获取画像、策略、任务、观察、模拟摘要，避免多接口拼装造成加载状态混乱。
   - 替代方案：前端并发调用多个接口，短期可行但错误处理和权限边界分散。

## Risks / Trade-offs

- [Risk] 首页依赖多个服务，某个服务失败会影响整体加载 → Mitigation：聚合接口按模块返回局部状态，允许部分卡片降级展示。
- [Risk] 菜单调整影响用户习惯 → Mitigation：保留旧路由，并在相关页面提供返回我的策略或任务中心入口。
- [Risk] 新手文案过度简化 → Mitigation：保留“查看解释”和详情入口，不隐藏必要风险。

## Migration Plan

- 新增首页路由并将 `/investment` 默认重定向到首页。
- 调整侧边栏个人投资助手子菜单。
- 保留 `/investment/screening/:taskId?` 和 `/investment/checkup/:taskId?`。
- 如需回滚，只需恢复默认重定向和菜单入口，新增首页不影响旧页面。
