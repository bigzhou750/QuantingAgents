## Purpose

为已登录用户提供一个与现有股票分析功能隔离的自然语言金融研究工作台，使用户能够观察 Agent 的研究过程、数据证据、工具调用、ReAct 轨迹和 Swarm 进度，并获得可追溯的研究结果。

## ADDED Requirements

### Requirement: 用户可以创建和管理研究会话

系统 SHALL 允许已登录用户创建、读取、重命名和删除属于自己的自然语言研究会话。会话 MUST 记录所属用户，并且用户只能访问自己的会话。

#### Scenario: 创建研究会话
- **WHEN** 已登录用户从研究工作台创建会话
- **THEN** 系统创建一个唯一会话，并返回可用于发送消息和订阅事件的会话标识

#### Scenario: 访问其他用户的会话
- **WHEN** 用户请求不属于自己的会话
- **THEN** 系统拒绝请求并且不得返回该会话的消息、trace、文件或运行状态

### Requirement: 用户可以发送自然语言研究请求

系统 SHALL 允许用户在研究会话中发送自然语言请求，并启动对应的 Agent 研究任务。请求 MUST 绑定当前用户、会话和任务标识。

#### Scenario: 正常发送研究请求
- **WHEN** 用户发送非空且未超过限制的自然语言请求
- **THEN** 系统接受请求，创建可追踪的研究任务，并返回任务和尝试执行标识

#### Scenario: 空请求或超长请求
- **WHEN** 用户发送空内容或超过系统限制的内容
- **THEN** 系统拒绝请求并返回可识别的校验错误，不启动 Agent Worker

### Requirement: 工作台提供流式 Agent 事件

系统 SHALL 通过 SSE 向研究工作台推送会话事件，包括文本增量、思考状态、工具调用、工具结果、数据校验、证据、ReAct 轨迹、Swarm 状态、完成、失败和取消事件。

#### Scenario: 订阅活动会话
- **WHEN** 用户订阅自己拥有的活动会话事件流
- **THEN** 系统建立 `text/event-stream` 连接并持续发送有序事件

#### Scenario: SSE 连接断开后恢复
- **WHEN** 用户使用最近一次事件标识重新连接
- **THEN** 系统从该事件之后重放可用事件，并避免重复发送已确认的事件

#### Scenario: 订阅不存在或无权限的会话
- **WHEN** 用户订阅不存在或不属于自己的会话
- **THEN** 系统返回明确错误，且不得建立可读取其他会话事件的连接

### Requirement: 工作台展示可审计的研究过程

系统 SHALL 展示 Agent 输出对应的工具调用、数据来源、校验结果、证据引用、ReAct 过程摘要和 Swarm 子任务状态。展示内容 MUST 与实际持久化运行记录保持一致。

#### Scenario: 工具调用成功
- **WHEN** Agent 完成一次工具调用并返回结果
- **THEN** 工作台展示工具名称、执行状态、必要的参数摘要、结果摘要和关联时间信息

#### Scenario: 工具调用失败
- **WHEN** 工具调用失败或返回不可用数据
- **THEN** 工作台展示失败状态和可诊断信息，并保留该失败事件在研究记录中

#### Scenario: Swarm 运行中
- **WHEN** Agent 启动多智能体 Swarm 研究
- **THEN** 工作台展示 Swarm 运行状态、子任务状态、进度和最终汇总结果

### Requirement: 工作台支持任务控制

系统 SHALL 允许用户查看自己研究任务的状态，并取消仍在运行的研究任务。取消操作 MUST 只影响当前用户授权的任务。

#### Scenario: 用户取消运行中的任务
- **WHEN** 用户取消自己拥有且仍在运行的研究任务
- **THEN** 系统向 Worker 发出取消请求，任务最终进入取消或已停止状态，并向 SSE 推送终止事件

#### Scenario: 重复取消已结束任务
- **WHEN** 用户取消已完成、失败或已取消的任务
- **THEN** 系统返回幂等结果，不重新启动或修改已结束的研究任务

### Requirement: 研究任务与现有任务中心兼容

系统 SHALL 将自然语言研究任务作为一种新增任务类型呈现在现有任务中心中，并保留现有单股分析、批量分析任务的状态和查询行为。

#### Scenario: 任务中心列出研究任务
- **WHEN** 用户查看自己的任务中心
- **THEN** 系统返回其有权访问的自然语言研究任务，并显示统一的生命周期状态、创建时间、完成时间和结果入口

#### Scenario: 查询现有分析任务
- **WHEN** 用户查询既有单股或批量分析任务
- **THEN** 系统行为和数据格式保持兼容，不因新增研究任务类型而改变既有任务

### Requirement: 高风险工具调用保留权限和审计上下文

系统 SHALL 将文件写入、Shell、交易连接和其他高风险工具调用关联到当前用户、会话、任务和操作日志。未满足权限要求的调用 MUST 被拒绝或进入既有确认流程。

#### Scenario: 允许的高风险工具调用
- **WHEN** 用户具备所需权限并触发高风险工具
- **THEN** 系统执行调用，并记录调用主体、目标、结果状态和关联任务

#### Scenario: 不允许的高风险工具调用
- **WHEN** 用户不具备所需权限或未完成必要确认
- **THEN** 系统阻止调用，记录拒绝原因，并向工作台发送可识别的拒绝事件
