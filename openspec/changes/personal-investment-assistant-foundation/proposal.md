## Why

当前项目已经具备股票研究、自然语言交互、自选股和模拟交易的基础，但还不是一个“懂用户”的个人投资助手。要面向炒股新手做商用产品，系统必须先知道用户的投资画像、持仓约束和策略偏好，才能把研究结果转成可执行、可解释、可复盘的个性化建议。

本次变更将把“个人信息管理页 + 策略管理 + 策略选股 + 策略体检”收敛为一条连续工作流，并把这些上下文接入 VibeAgent 研究链路，为后续的复盘、扩展策略和更完整的验证能力打基础。

## What Changes

- 新增个人投资画像能力，用于维护资金区间、风险偏好、交易风格、禁投规则、真实持仓和默认研究上下文。
- 新增策略管理能力，用于维护可复用的策略模板、参数和适用市场说明。
- 新增策略选股能力，允许用户基于所选策略手动发起任务，输出候选股票池和命中原因，而不是买卖指令。
- 新增策略体检能力，对某个策略在当前市场环境下的适配度做轻量评估，输出风险提示、近期表现摘要和适用性结论。
- 将个人画像和策略上下文注入 VibeAgent 的研究输入，使自然语言研究结果能结合用户约束进行解释。
- 更新 README 和产品定位说明，明确项目是基于 TradingAgents-CN 二次开发并接入 vibe-trading 自然语言交互模式的个人投资助手。
- **非目标**：本次不实现完整历史回测平台、不接入券商实盘交易、不做会员订阅或多租户计费能力。

## Capabilities

### New Capabilities
- `personal-investment-assistant`: 个人投资画像、策略管理、策略选股、策略体检和 VibeAgent 上下文注入。

### Modified Capabilities
- `natural-language-research-workbench`: 研究工作台需要支持带入用户画像与策略上下文的研究任务输入。
- `embedded-vibe-agent-runtime`: runtime 需要接收并使用结构化研究上下文，而不只依赖纯文本 prompt。

## Impact

- **前端**：新增个人信息管理页和策略管理页；研究工作台需要支持选择画像和策略上下文。
- **后端**：新增画像、策略、筛选任务和体检任务相关 API、MongoDB 集合和校验逻辑。
- **VibeAgent 链路**：研究输入需要携带受控的用户上下文摘要，保证个性化结果可追溯。
- **文档**：README 和用户说明需要更新为“个人投资助手”定位，并明确策略选股和策略体检的输出边界。
- **数据**：需要新增画像、策略定义、筛选结果、体检结果和任务审计记录的持久化结构。
