## Purpose

为管理员提供统一的已注册账号管理能力，包括账号展示、检索、创建、详情、启停、角色分配、密码重置、资料/配额更新和安全删除归档，并保证操作可审计、不可由普通用户越权执行。

## ADDED Requirements

### Requirement: 管理员账号管理入口
系统 MUST 为管理员提供账号管理页面，普通用户 MUST 无法进入该页面，未认证用户 MUST 先完成登录。

#### Scenario: 管理员访问账号管理页
- **WHEN** 已认证管理员访问账号管理页面
- **THEN** 系统显示已注册账号管理界面，并提供账号列表、检索、创建和管理操作入口

#### Scenario: 普通用户访问账号管理页
- **WHEN** 已认证普通用户访问账号管理页面
- **THEN** 系统拒绝访问并提示无权限，不显示任何账号数据

### Requirement: 注册账号列表与检索
系统 MUST 向管理员返回所有已注册账号的非敏感信息，并支持按关键字、账号状态分页检索；返回信息 MUST 包含用户名、邮箱、管理员角色、激活状态、验证状态、创建时间、最后登录时间、配额和统计信息，MUST 不包含密码、密码哈希或 Token。

#### Scenario: 查看全部已注册账号
- **WHEN** 管理员打开账号列表
- **THEN** 系统按分页返回账号摘要，并按角色和状态显示每个账号的当前状态

#### Scenario: 搜索和筛选账号
- **WHEN** 管理员输入用户名或邮箱关键字并选择账号状态
- **THEN** 系统只返回匹配当前关键字和状态的账号，并保持分页信息准确

#### Scenario: 列表响应包含管理员角色
- **WHEN** 管理员请求账号列表
- **THEN** 每个账号响应都包含 `is_admin` 字段，前端可据此展示管理员角色

### Requirement: 账号详情
系统 MUST 允许管理员查看单个账号的完整非敏感信息，包括激活状态、验证状态、管理员角色、创建和更新时间、最后登录时间、邮箱、偏好、配额与用量统计。

#### Scenario: 查看账号详情
- **WHEN** 管理员选择某个已注册账号
- **THEN** 系统展示该账号的非敏感详情，不展示任何密码或认证凭据

#### Scenario: 查看不存在的账号
- **WHEN** 管理员请求一个不存在的账号详情
- **THEN** 系统返回明确的 404 错误，不泄露其他账号数据

### Requirement: 管理员创建账号
系统 MUST 允许管理员通过账号管理界面创建新账号，提交用户名、邮箱、密码和可选管理员角色；用户名和邮箱 MUST 唯一，密码 MUST 满足现有密码策略，创建成功后 MUST 记录审计日志。

#### Scenario: 创建普通账号
- **WHEN** 管理员提交合法的用户名、邮箱和密码且未指定管理员角色
- **THEN** 系统创建激活的普通账号并返回非敏感账号摘要

#### Scenario: 创建管理员账号
- **WHEN** 管理员提交合法信息并指定管理员角色
- **THEN** 系统创建管理员账号并返回该账号的管理员角色标记

#### Scenario: 创建重复账号
- **WHEN** 管理员提交已存在的用户名或邮箱
- **THEN** 系统拒绝创建并返回明确的业务错误，不覆盖已有账号

### Requirement: 启停账号
系统 MUST 允许管理员启用或禁用账号；禁用账号 MUST 立即失去登录和刷新凭据能力，已有 Token MUST 在鉴权时失效；启用操作 MUST 恢复账号登录能力；两类操作 MUST 记录审计日志。

#### Scenario: 禁用账号
- **WHEN** 管理员禁用某个激活账号
- **THEN** 该账号被标记为禁用，其现有 Token 和新登录请求均被拒绝

#### Scenario: 启用账号
- **WHEN** 管理员启用某个已禁用账号
- **THEN** 该账号重新获得登录能力，但仍受密码策略和认证防护约束

#### Scenario: 禁用不存在的账号
- **WHEN** 管理员尝试禁用不存在的账号
- **THEN** 系统返回 404，不产生状态变更

### Requirement: 角色分配
系统 MUST 允许管理员把普通账号设为管理员或移除管理员角色；当前管理员 MUST 不能移除自己的管理员角色；角色变更 MUST 使该账号既有会话失效并记录审计日志。

#### Scenario: 提升普通用户为管理员
- **WHEN** 管理员将某个普通账号设置为管理员角色
- **THEN** 系统更新该账号角色并使其后续访问具备管理员权限

#### Scenario: 移除其他管理员角色
- **WHEN** 管理员移除另一个管理员的角色
- **THEN** 系统更新目标账号角色，该账号后续不再具备管理员权限

#### Scenario: 阻止移除自身管理员角色
- **WHEN** 管理员尝试移除自己的管理员角色
- **THEN** 系统拒绝操作并返回明确错误，账号角色保持不变

### Requirement: 重置密码
系统 MUST 允许管理员为指定账号重置密码；新密码 MUST 满足现有密码策略，重置后 MUST 使该账号旧会话失效；响应和审计日志 MUST 不包含新密码明文或哈希。

#### Scenario: 管理员重置账号密码
- **WHEN** 管理员为已注册账号提交符合策略的新密码
- **THEN** 系统更新密码、撤销该账号旧会话并记录审计日志

#### Scenario: 重置不存在的账号密码
- **WHEN** 管理员为不存在的账号重置密码
- **THEN** 系统返回 404，不创建账号也不修改任何数据

### Requirement: 更新账号资料与配额
系统 MUST 允许管理员更新账号邮箱、每日配额和并发限制；邮箱 MUST 保持全局唯一；该接口 MUST 不能修改密码哈希、Token 或管理员角色，角色变更必须走独立角色接口。

#### Scenario: 更新账号邮箱和配额
- **WHEN** 管理员为已注册账号提交未占用的邮箱和合法配额
- **THEN** 系统更新对应账号字段并返回更新后的非敏感账号信息

#### Scenario: 更新为已占用邮箱
- **WHEN** 管理员将账号邮箱更新为另一个账号已使用的邮箱
- **THEN** 系统拒绝更新并返回明确错误，原账号数据保持不变

### Requirement: 安全删除与归档账号
系统 MUST 为管理员提供删除账号能力，但删除 MUST 采用先禁用后归档的安全流程；归档账号 MUST 无法登录，其用户名和邮箱可被释放或保留由实现决定，但归档后 MUST 不再参与普通查询和登录；系统 MUST NOT 因账号删除而物理删除该账号拥有的分析记录、任务、会话或记忆，除非实现提供独立的显式数据清理流程。

#### Scenario: 删除普通账号
- **WHEN** 管理员确认删除某个非当前登录账号
- **THEN** 系统先禁用该账号，再将其标记为已删除/已归档，并保留其历史资源为隔离或不可登录状态

#### Scenario: 阻止删除当前管理员
- **WHEN** 管理员尝试删除当前登录账号
- **THEN** 系统拒绝操作并返回明确错误，当前账号保持不变

#### Scenario: 已删除账号尝试登录
- **WHEN** 已删除/已归档账号使用旧凭据尝试登录
- **THEN** 系统拒绝登录，且不向登录者暴露账号已被删除的额外敏感信息

### Requirement: 管理员操作审计
所有账号管理操作 MUST 记录操作者、目标账号、操作类型、结果和时间；创建、启停、角色、密码重置、资料/配额更新和删除归档 MUST 写入现有审计日志；普通用户调用任一管理操作 MUST 返回 403 且不产生变更。

#### Scenario: 管理操作写入审计
- **WHEN** 管理员执行任一账号管理操作
- **THEN** 系统生成包含操作者、目标账号、操作类型和结果的审计记录

#### Scenario: 普通用户调用管理接口
- **WHEN** 普通用户调用任一账号管理接口
- **THEN** 系统返回 403，不返回账号数据，不改变任何目标账号

### Requirement: 管理界面交互与失败反馈
账号管理界面 MUST 提供加载、空数据、错误和成功反馈；禁用、角色变更、重置密码和删除归档等高风险操作 MUST 要求管理员二次确认；操作失败时 MUST 保持界面状态可恢复并显示明确错误。

#### Scenario: 列表加载与空状态
- **WHEN** 管理员打开账号列表且系统尚未返回数据或没有任何账号
- **THEN** 界面显示加载状态或空状态，不显示错误数据

#### Scenario: 高风险操作二次确认
- **WHEN** 管理员触发禁用、角色变更、重置密码或删除归档操作
- **THEN** 系统先展示确认信息，仅在管理员确认后提交请求

#### Scenario: 操作失败反馈
- **WHEN** 任一账号管理请求返回业务错误或网络错误
- **THEN** 界面显示可理解的错误信息，已打开的详情和列表状态不丢失
